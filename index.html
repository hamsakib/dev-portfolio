About me

From curious student to shipping a real product

My programming journey started with Computer Science at North South University, where I learned the fundamentals: C, data structures and how computers really work. I wanted to build things people actually use, so I went deep into web development, learning HTML, CSS and JavaScript, then React, Node.js, Express and MongoDB through Programming Hero's Complete Web Development course and a long list of hands-on projects.

In 2026 I put that to work for real. With my co-founder I launched Skinmax, an online skincare shop in Bangladesh, and I built the whole platform myself on Next.js and PostgreSQL: the storefront, phone login, checkout, courier integrations, an AI shopping assistant and the admin back office. Seeing real customers order from code I wrote taught me more than any tutorial: performance, security, debugging in production and owning what I ship.

The work I enjoy most is full-stack product work, where I take a feature from database schema to API to a polished, responsive interface. I also love automation and AI: connecting LLMs to real data so they do useful work instead of just chatting.

Outside programming I enjoy football, video editing and photography, and I like exploring new food spots around Dhaka. I'm patient, curious and happiest when a hard bug finally makes sense.
